# Задание 6. Файлы и исключения

Запуск из папки: `py 1.py`, `py 2.py`, `py 3.py`. Входные файлы с примерами данных лежат рядом (там специально есть ошибочные строки).

Общая схема во всех трёх:

- чтение через `with open(...)` внутри `try`, снаружи ловим `FileNotFoundError`, `PermissionError`, `OSError`;
- каждая строка разбирается в своём `try`: плохая строка — сообщение и `continue`, программа не падает;
- запись результата тоже в `try` с `with`, при ошибке (нет прав и т.п.) — сообщение.

`PermissionError` — подкласс `OSError`, поэтому ловим его раньше.

## 1. Ускорение свободного падения

`input.txt` → `output.txt`. h = 5 м.

- пустая строка или не число (`ValueError`) — пропуск;
- `t <= 0` — сами бросаем `ZeroDivisionError` и пропускаем с предупреждением;
- для каждого t считаем `g = 2h / t^2`, потом среднее время и среднее g.

На примере: 4 корректных измерения, среднее t ≈ 1.005 с, среднее g ≈ 9.90 м/с².

## 2. Температурный коэффициент сопротивления

`data.csv` → `result.txt`.

- строка делится по запятой, должно быть ровно два числа, иначе `ValueError`;
- если не разобралась первая строка — это заголовок;
- первая корректная пара — опорная (T0, R0);
- `α = (R - R0) / (R0 (T - T0))`; при `T = T0` или `R0 = 0` Python сам бросает `ZeroDivisionError` — пропускаем.

На примере: 3 точки, α ≈ 0.004 1/°C (как у меди).

## 3. Спектр

`spectrum.txt` → `max_peak.txt`.

- пустые строки и `#` пропускаем;
- `split()` без аргумента режет и по пробелам, и по табам;
- максимум ищем по ходу чтения;
- если корректных строк ноль — `raise ValueError("Нет данных для анализа")`, ловится тем же `try`.

На примере: максимум на 500 нм, I = 7.8.
