# Вариант 2

Запуск из папки варианта: `py 1.py`, потом ввод.

## 1. Логические выражения

Точка `(x, y)` и круг с центром `(0, 0)` радиуса 5. В условии проверка `x² + y² < 5²`, примеры:

- `3 4` → `Точка принадлежит кругу`
- `6 1` → `Точка вне круга`

`3² + 4² = 25`, это **граница** круга. При строгом `<` точка не внутри, а в примере она принадлежит. Поэтому в коде `<=`, чтобы сойтись с примером.

Ввод: два числа в одной строке.

## 2. Циклы

Числа по одному, конец ввода — `0`. Нужен максимум среди введённых, ноль в сравнение не входит.

Первое число запоминаем как текущий максимум, дальше в цикле обновляем, пока не придёт `0`.

## 3. Функции

`count_upper_lower(s)` считает латинские заглавные `A–Z` и строчные `a–z`, возвращает кортеж `(заглавные, строчные)`.

Русские буквы, цифры и пробелы не считаем — в задании только латиница. Строку берём из `input()` и печатаем результат функции.
