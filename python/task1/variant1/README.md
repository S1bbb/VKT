# Вариант 1

Запуск из папки варианта: `py 1.py`, потом ввод.

## 1. Логические выражения

Нужно прочитать целое число и ответить, оно **одновременно** положительное и чётное. Печатаем `True` или `False`.

- `8` → `True`
- `-4` → `False` (отрицательное, хоть и чётное)

В коде это одно выражение: `n > 0 and n % 2 == 0`. `print` сам пишет `True`/`False`, отдельно строки собирать не надо.

## 2. Циклы

`while` от 20 вниз до 1 включительно. Каждое число с новой строки.

Шаг `i -= 1`. Цикл пока `i >= 1`, иначе ноль тоже вылезет.

## 3. Функции

`rectangle_area(a, b)` возвращает площадь `a * b`. Стороны считываем, вызываем функцию, печатаем результат.

Ввод — два числа, каждое с новой строки. Тип `float`, чтобы не ломаться на `2.5`.
