# Вариант 3

Запуск из папки варианта: `py 1.py`, потом ввод.

## 1. Логические выражения

Три целых числа — стороны. Треугольник собирается, если для каждой пары сумма **строго** больше третьей стороны.

- `3 4 5` → `Можно`
- `1 2 3` → `Нельзя` (`1 + 2` не больше `3`)

Ввод: три числа в одной строке.

## 2. Циклы

Первые `N` чисел Фибоначчи, ряд начинается с `0 1`. Нужен `for`, не `while`.

- `7` → `0 1 1 2 3 5 8`

Две переменные: текущее и следующее. На каждом шаге печатаем текущее и сдвигаем пару.

## 3. Функции

Рекурсивная `sum_of_digits(n)` — сумма цифр. Число может быть отрицательным: `-1234` → `10`.

Сначала `abs(n)`, знак на сумму не влияет. Если цифр одна — возвращаем её, иначе последняя цифра `n % 10` плюс вызов для `n // 10`.
