# Задание 7. Многочлены

Запуск из папки: `py 1.py` и `py 2.py`. Ввода нет, многочлены заданы прямо в коде.

В обоих файлах одно и то же: сложение, умножение, вывод и значение в точке. Разница только в том, как хранится многочлен.

Пример из кода:

- `p1 = x^2 + 7`
- `p2 = -x^2 + 3x`
- сумма → `3x + 7`
- произведение → `-x^4 + 3x^3 - 7x^2 + 21x`
- `p1(2)` → `11`

## 1. Список

Индекс — степень, значение — коэффициент. `x^2 + 7` это `[7, 0, 1]`.

- `normalize` убирает нули с конца, чтобы `[3, 7, 0]` не считался многочленом второй степени.
- `add` — заводим список нулей длиной как у большего и прибавляем оба по индексам.
- `mul` — каждый с каждым, `x^i * x^j = x^(i+j)`, поэтому результат кладём в `res[i + j]`. Длина ответа `len(p1) + len(p2) - 1`.
- `eval_poly` — схема Горнера: идём от старшей степени, `res = res * x + c`. Без возведения в степень.

## 2. Словарь

Ключ — степень, значение — коэффициент. Храним только ненулевые: `x^2 + 7` это `{0: 7, 2: 1}`.

Удобно, когда степени большие, а членов мало: `x^100` — один ключ, а не список на 101 элемент.

- `clean` выкидывает ключи с нулём (например, после `x^2 + (-x^2)`).
- `add` и `mul` — то же самое, что в списке, только через `res.get(k, 0)`, потому что ключа может ещё не быть.
- `eval_poly` — просто сумма `c * x ** k`. Горнер тут неудобен, степени идут с пропусками.

## Вывод

`print_poly` одинаковый в обоих файлах. Идём от старшей степени к младшей:

- нулевые коэффициенты пропускаем;
- единицу перед `x` не пишем: `x`, а не `1x`; `-x`, а не `-1x`;
- у первого члена минус слитно (`-x^2`), дальше знаки через пробелы (` + `, ` - `);
- если всё сократилось — печатаем `0`.
